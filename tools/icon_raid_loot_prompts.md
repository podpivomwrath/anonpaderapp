# Иконки рейдового лута: 8 штук

Панцирь Тавра (рейд «Поле без могил»), Маска Архивариуса («Безликий архив») и по три вещи их ковки. Пока картинок нет, мини-апп показывает вместо них базовый панцирь и маску.

Квадрат 1:1. Промт копировать целиком - сборка иконок находит картинку по его тексту. Положить в img/ с описью, как обычно, затем python tools/icon_assets.py.
