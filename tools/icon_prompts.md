# Промты для генерации иконок

Собрано из контента игры: `python tools/icon_prompts.py > tools/icon_prompts.md`.
После добавления предметов перегенерировать — руками список разойдётся с игрой на первой же новой вещи.

Промты на английском: модели генерации понимают его точнее. Общий стилевой хвост дописан к каждому — без него набор выйдет из разных миров.

Требования к обеим необычные: их видно каждую секунду, и они НЕ должны спорить с текстом - контраст низкий, в середине пусто, детали по краям.

Very low contrast, muted ash grey and rust brown with a single faint crimson glow at the monolith's base. Painterly, atmospheric, no characters, no text, no watermark, landscape 16:9
