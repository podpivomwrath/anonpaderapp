# Промты: добыча кровавого разлома

Пять иконок: два ларца и три свитка. Стиль - общий с иконками предметов
(`tools/icon_prompts.py`): один предмет по центру, тёмный фон, без текста.

Готовые картинки положить в `img/` под именами из таблицы и запустить
`python tools/icon_assets.py` - он сожмёт их и подключит к мини-аппу
(привязка по имени файла, `EXTRA_FILES`). Пока картинки нет, мини-апп
просто не показывает значок.

| Что | Файл |
|---|---|
| ⛏ Ларец руды | `ларец_руды.png` |
| 🧪 Ларец расходников | `ларец_расходников.png` |
| 📜 Свиток лечения | `свиток_лечения.png` |
| 📜 Свиток оберега | `свиток_оберега.png` |
| 📜 Свиток уязвимости | `свиток_уязвимости.png` |

Ларцы - одна серия с Пепельным ларцом (тот же размер и ракурс), но из
кровавого разлома: багровый отлив, запёкшаяся кровь на окованных углах.
Свитки - одна серия между собой: одинаковая форма свитка, различаются
печатью, цветом сургуча и тем, что проступает сквозь бумагу.
